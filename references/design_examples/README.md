# Design examples

Reference-only poster mockups (`comic_pop.png`, `comparison_split.png`,
`report_card.png`) showing layout styles Josh wants to keep in mind for
future poster designs. These are **not** generated by any template in
`scripts/templates.py` — there's no `render_comic_pop`, `render_comparison_split`,
or `render_report_card` function yet, so `generate_poster.py` can't reproduce
them. Kept here purely as visual inspiration until (if ever) someone builds a
matching template.
